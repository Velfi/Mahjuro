Relic text → description & flavor_spans

Load relics.json (file or drag-drop), edit the rule line and flavor, use B / I in the flavor box. Save writes the full array. More…

Rule is the plain-string description field (what players read as the mechanical summary). Flavor is rich-text flavor_spans for inspect UI. Changing relic in the dropdown saves the current relic’s edits in memory first (then save file when you are ready). Browsers that support it open a real save dialog; otherwise you get a download of relics.json to move into assets/data/. Object art uses assets/textures/relics/source/<id>_object.png relative to this page; if images are missing, serve the repo from its root (e.g. python3 -m http.server) and open this HTML over http://localhost/….

Line breaks → \n in JSON.
