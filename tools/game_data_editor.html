Mahjuro — game data JSON editor

Load ship data from assets/data/ (e.g. relics.json, bosses.json, yaku.json, seasons.json, tags.json, talismans.json, tile_packs.json, zodiacs.json) via the file picker or drag and drop. Row pick is by id. Save writes the full document (array or zodiacs.json wrapper). Browsers with showSaveFilePicker get a save dialog; others download using the loaded filename.

Line breaks become \n in JSON.
