# **Mahjuro — Progression Blueprint**

## **1. Progression Layers**

Mahjuro has three main progression layers:

| Layer                     | Description                                            | Examples                                                              |
| ------------------------- | ------------------------------------------------------ | --------------------------------------------------------------------- |
| **In-Run Progression**    | Things you acquire **during a run** to affect that run | Relics, tile pool modifiers, temporary rule changes                   |
| **Meta Progression**      | Things you unlock **between runs**                     | New relics, yaku, tile types, rule modifiers                          |
| **Knowledge Progression** | Player learning over time                              | Understanding patterns, scoring combos, multipliers, hand recognition |

---

## **2. In-Run Progression**

### **A. Relics (20 Examples)**

Relics modify scoring, tile behavior, or rules. Stackable and often chaotic:

| Relic Name        | Effect                                                      |
| ----------------- | ----------------------------------------------------------- |
| Triplet Boost     | Triplets score ×2                                           |
| Sequence Surge    | Sequences hit all enemies / affect multiple targets         |
| Pair Power        | Pairs count as triplets                                     |
| Honor Fury        | Honor tiles give ×3 score                                   |
| Bamboo Charm      | All bamboo tiles +2 points                                  |
| Red Dragon Rage   | Triplets of Red Dragon ×5                                   |
| Green Luck        | Any hand without honors heals HP                            |
| White Silence     | Winning hand freezes round timer for 2 turns                |
| Joker Tile        | Can act as any tile once per round                          |
| Overflow          | Duplicate tiles allowed this round                          |
| Quick Draw        | Draw 2 tiles per turn once                                  |
| Chain Reaction    | Completing a hand triggers auto scoring on next set         |
| Multiplier Master | +10% multiplier for consecutive winning hands               |
| Set Magnet        | Completing a set pulls a random matching tile from the wall |
| Wild Winds        | Winds act as wildcards for sets                             |
| Dragon Echo       | Triplets cause adjacent sets to score                       |
| Reverse Tile      | Swap value of 2 tiles once                                  |
| Stealth Tile      | First discard does not reveal to modifier effects           |
| Locked Set        | Triplets cannot be broken for 3 turns                       |
| Lucky Pair        | Pairs give a bonus multiplier this round                    |

---

### **B. Tile Pool Modifiers**

* Add extra copies of a suit (e.g., “+4 Bamboo”)
* Remove a suit entirely (“No Character tiles”)
* Introduce special wild tiles
* Introduce cursed tiles (negative effect if included in hand)
* Early-game: only base sets
* Mid-game: wilds and upgraded tiles appear

---

### **C. Round Modifiers / Temporary Rules**

* “Sequences can wrap (8-9-1)”
* “Pairs count double”
* “Must win in 3 turns”
* “Duplicate tiles allowed”
* “Triplets of honors score triple”
* “Hand without sequences = extra bonus”
* “Random tiles are locked for 1 turn”

**Boss rounds** stack modifiers for chaos. Example:

* “No sequences, triplets ×3, duplicate tiles allowed”

---

## **3. Meta Progression (Between Runs)**

### **A. Rule Unlock Tree**

| Unlock Level | New Rule                               | Notes                   |
| ------------ | -------------------------------------- | ----------------------- |
| Level 1      | Basic hands: Pair, Triplet, Sequence   | First runs              |
| Level 2      | Simple Yaku: All Triplets, All Simples | Adds scoring depth      |
| Level 3      | Riichi / Lock-In Bet                   | Optional risk/reward    |
| Level 4      | Dora Tiles                             | Bonus tile scoring      |
| Level 5      | Honors scoring multipliers             | Dragons/Winds           |
| Level 6      | Flowers / Seasons                      | Cosmetic + bonus points |
| Level 7      | Rule-breaking relics appear more often | Chaos scaling           |

---

### **B. Content Unlocks**

* New relics (see above)
* New tile types: flowers, seasons
* New yaku unlocks
* New relics (including stronger late-run relic pools)
* New tile types: flowers, seasons
* New rule modifiers and boss pressure

---

### **C. Permanent Upgrades (Light Touch)**

* +1 HP
* Starting relic slot unlocked
* Slightly better tile odds for favored suit

---

## **4. Knowledge Progression / Player Feedback**

* Highlight near-complete hands
* End-of-run summary:

  * Most used patterns
  * Missed hands / multipliers
  * Average score per hand
* Optional tutorials unlock gradually:

  * Early: “Pairs, Triplets, Sequences”
  * Mid: “Yaku bonuses explained”
  * Late: “Riichi / Dora mechanics explained”

---

## **5. Sample Run Structure**

1. **Start Run** – Choose starting style (Sequence, Triplet, Risky)
2. **Rounds 1–3** – Base hands, small relics
3. **Mid Run** – Introduce modifiers, wild tiles, relic stacking
4. **Mini-Boss / Challenge Round** – Forced modifiers, scoring challenge
5. **Late Run / Boss Round** – Multiple modifiers, chaos rules, score target
6. **End of Run** – Unlock relics, tiles, and rules for next run

---

## **6. Visual / Feedback Systems**

* Tile drag & drop with snapping
* Near-complete hand highlights
* Visual multipliers for relic stacking
* Score pop-ups
* Temporary rule notifications (clear, colorful)
* End-of-run summary dashboards

---

## **7. Example Relic + Modifier Synergy**

* Relic: **Triplet Boost ×2**
* Modifier: “Duplicate tiles allowed”
* Effect: Build 4 triplets of the same tile → absurd score
* Player Feels: **Strategic chaos + reward for pattern recognition**

## **8. Early, Mid, Late Game Flow**

| Phase | Focus            | Unlocks                                                                |
| ----- | ---------------- | ---------------------------------------------------------------------- |
| Early | Learn basic sets | Simple relics, only base tiles                                         |
| Mid   | Build combos     | Advanced relics, modifiers, simple yaku                                |
| Late  | Full chaos       | Rule-breaking relics, wild tiles, Riichi optional, complex multipliers |
